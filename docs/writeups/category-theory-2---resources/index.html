CAT02: Resources

The 2nd CAT write-up is about the categorical formalism of resources, and transforming one set of resources into another. It covers monoidal preorders, wiring diagrams, monoidal monotone maps, and V-categories.

Friday, June 14, 2024
Tags:

Symmetric Monoidal Preorders

Def 2.1: A symmetric monoidal structure on a preorder (X,≤)(X,≤)(X,≤) consists of two constituents: (i) an element I∈XI \in XI∈X, called the monoidal unit, (ii) and a function ⊗:X×X→X\otimes: X \times X \rightarrow X⊗:X×X→X, called the monoidal product. These constituents must satisfy the following properties:

  • monotonicity: ∀x1,x2,y1,y2∈X\forall x_1, x_2, y_1, y_2 \in X∀x1​,x2​,y1​,y2​∈X, if x1≤y1x_1 \le y_1x1​≤y1​ and x2≤y2x_2 \le y_2x2​≤y2​, then x1⊗x2≤y1⊗y2x_1 \otimes x_2 \le y_1 \otimes y_2x1​⊗x2​≤y1​⊗y2​.
  • unitality: ∀x∈X\forall x \in X∀x∈X, I⊗x=xI \otimes x = xI⊗x=x and x⊗I=xx \otimes I = xx⊗I=x holds.
  • associativity: ∀x,y,z∈X\forall x,y,z \in X∀x,y,z∈X, (x⊗y)⊗z=x⊗(y⊗z)(x\otimes y)\otimes z = x \otimes (y\otimes z)(x⊗y)⊗z=x⊗(y⊗z).
  • symmetry: ∀x,y∈X,x⊗y=y⊗x\forall x,y \in X, x\otimes y = y\otimes x∀x,y∈X,x⊗y=y⊗x.1

Def 2.2: A preorder equipped with a symmetric monoidal structure, (X,≤,I,⊗)(X,\le,I,\otimes)(X,≤,I,⊗), is called a symmetric monoidal preorder.

Example 2.1(The Booleans): B={true,false}\mathbb{B} = \{true, false\}B={true,false} with false<truefalse < truefalse<true is the simplest nontrivial preorder. We can define the monoidal unit be true and the monoidal product be ∧\wedge∧(AND). Then we have a monoidal preorder which we denote Bool:=(B,≤,true,∧)Bool := (\mathbb{B}, \le ,true, \wedge )Bool:=(B,≤,true,∧).

Wiring Diagrams

Wiring diagrams are visual representations for building new releationships from old. In a preorder without a monoidal structure, the relations are chained in series.

With a symmetric monoidal structure, relations could be arranged in parallel as well. The whole wiring diagram above says “if t≤v,w+u≤x+z,v+x≤yt\le v, w+u\le x+z, v+x\le yt≤v,w+u≤x+z,v+x≤y, then t+u≤y+zt+u\le y+zt+u≤y+z”.

We could draw two wires in parallel to represent the monoidal product of two labels. The validity of the box above corresponds to x1⊗x2≤y1⊗y2⊗y3x_1\otimes x_2 \le y_1 \otimes y_2 \otimes y_3x1​⊗x2​≤y1​⊗y2​⊗y3​.
