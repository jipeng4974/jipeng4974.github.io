CAT01: Orders

The 1st CAT write-up gives an order-theoretic warm-up for the full-fledged category theory. It covers preorders, meets/joins, monotone maps and Galois connections.

Monday, February 26, 2024
Tags:
  • Math

Preorders

Starting from sets and subsets, we can define the relation between sAAA and BBB as a subset R∈A×BR \in A\times BR∈A×B.

Every function is a relation, satisfying 2 properties:

  1. ∀a∈A\forall a \in A∀a∈A, there exists b∈Bb \in Bb∈B, such that (a,b)∈R(a,b)\in \mathbb{R}(a,b)∈R
  2. ∀a,b1,b2\forall a, b_1, b_2∀a,b1​,b2​, if (a,b1)∈R(a,b_1) \in R(a,b1​)∈R and (a,b2)∈R(a, b_2) \in \mathbb{R}(a,b2​)∈R, then b1=b2b_1 = b_2b1​=b2​.

Order, equivalence, tolerance are all relations.

A function f:A↣Bf: A\rightarrowtail Bf:A↣B is called injection if ∀a1,a2,b\forall a_1, a_2, b∀a1​,a2​,b, if (a1,b),(a2,b)∈R(a_1, b), (a_2, b) \in R(a1​,b),(a2​,b)∈R, then a1=a2a_1 = a_2a1​=a2​.

A function f:A↠Bf: A\twoheadrightarrow Bf:A↠B is called surjection if ∀b∈B\forall b \in B∀b∈B, there exists an a∈Aa \in Aa∈A, such that f(a)=bf(a) = bf(a)=b.

A function f:A↣≅Bf: A \overset{\cong} \rightarrowtail Bf:A↣≅​B is called bijection if it is both surjective and injective.

An identity function on a set XXX, denoted idXid_XidX​. It is the bijective function idX(x)=xid_X(x) = xidX​(x)=x.

A partition on AAA is just a surjection on some other set PPP: A↠PA \twoheadrightarrow PA↠P.

We can order partitions: A↠P1A \twoheadrightarrow P_1A↠P1​, A↠P2A \twoheadrightarrow P_2A↠P2​. We say P1⩽P2P_1 \leqslant P_2P1​⩽P2​, if there is a function P1→P2P_1 \rightarrow P_2P1​→P2​ making the diagram commute: A↠P1→P2A \twoheadrightarrow P_1 \rightarrow P_2A↠P1​→P2​.

So A↠AA \twoheadrightarrow AA↠A is the minimum partition, and the A↠1‾A \twoheadrightarrow \underline{1}A↠1​ is the maximum partition.

An preorder is

  1. a set SSS, and
  2. a relation ≤ ⊆S×S≤ \: \subseteq S \times S≤⊆S×S1

satisfying 2 properties:

  1. S≤SS ≤ SS≤S. 2
  2. ∀S1\forall S_1∀S1​, S2S_2S2​, S3S_3S3​, if S1≤S2S_1 ≤ S_2S1​≤S2​ and S2≤S3S_2 ≤ S_3S2​≤S3​, then S1≤S3S_1 ≤ S_3S1​≤S3​. 3

A preorder is a category with at most one morphism between any two objects. Something slightly more complicated is that a preorder is a Bool-enriched category.

Meets and Joins

Order creates meets and joins.

Joining AAA and BBB, denoted by A∨BA\vee BA∨B, results in the least partition bigger than both AAA and BBB. That is A≤(A∨B)A ≤ (A\vee B)A≤(A∨B) and A≤(A∨B)A ≤ (A\vee B)A≤(A∨B). And for any C, if A≤CA ≤ CA≤C and B≤CB ≤ CB≤C then (A∨B)≤C(A\vee B) ≤ C(A∨B)≤C.

Put it formally. Let (P,≤)(P, ≤)(P,≤) be a preorder, and let A⊆PA \subseteq PA⊆P be a subset. We say that an element p∈Pp \in Pp∈P is a meet of AAA if

  1. ∀a∈A\forall a\in A∀a∈A, we have p≤ap≤ ap≤a4, and
  2. for all qqq such that q≤aq≤ aq≤a for all a∈Aa\in Aa∈A, we have that q≤pq≤ pq≤p5.

We write P=∧A=∧a∈Aa=a1∧a2∧...∧anP = \wedge A = \underset{a\in A}{\wedge} a = a_1 \wedge a_2 \wedge ... \wedge a_nP=∧A=a∈A∧​a=a1​∧a2​∧...∧an​

Similarly, we say that ppp is a join of AAA if

  1. ∀a∈A\forall a\in A∀a∈A, we have a≤pa≤ pa≤p6, and
  2. for all qqq such that a≤qa≤ qa≤q for all a∈Aa\in Aa∈A, we have that p≤qp≤ qp≤q7.

In this case, P=∨A=∨a∈Aa=a1∨a2∨...∨anP = \vee A = \underset{a\in A}{\vee} a = a_1 \vee a_2 \vee ... \vee a_nP=∨A=a∈A∨​a=a1​∨a2​∨...∨an​

Example 1: Truth Tables of the Booleans B\mathbb{B}B={T,F}$.

For example, the pairwise meets table of {T,F}(F≤T)\{T,F\}(F \leq T){T,F}(F≤T) happens to be the truth table for AND in elementary logic. A similar binary join computation will generate the truth table for OR.

Example 2: Power Sets, (P(x),≤)(P(x), ≤)(P(x),≤).

Example 3: (N,∣),a≤b(\mathbb{N}, |), a ≤ b(N,∣),a≤b, iff a∣ba|ba∣b

1 divides everything, so we start from 1. Here we have ∧\wedge∧ = gcd, ∨\vee∨ = lcm.

Example 4: There may be more than one meet/join.

This hasse diagram specifies a preorder where both ccc and ddd are meets of AAA. We have c≤dc≤ dc≤d and d≤cd≤ cd≤c, so c≅dc \cong dc≅d, that is ccc and ddd are isomorphic, which will be covered later; we generally do not run into trouble if we pretend they are equal though.

Example 5: Meets or joins may not exist.

Clearly things don’t always have a lower bound or a upper bound at all. There might be multiple lower bounds/upper bounds but these lower/upper bounds are non-comparable.

Throughout these examples, many familiar things can be characterized by this quite simple universal property, be it gcd/lcm, max/min, limits/colimits, or itersection/union.

The idea that things can be characterized by universal properties, implies we are closer to category theory now.

Monotone Maps

Preorders themselves can be related to one another. A monotone map is a structure-preserving map for preorders.

A monotone map between preorders (A,≤A)(A, ≤_A)(A,≤A​) and (B,≤B)(B, ≤_B)(B,≤B​) is a function f:A→Bf : A \rightarrow Bf:A→B such that, for all elements x,y∈Ax, y ∈ Ax,y∈A, if x≤Ayx ≤_A yx≤A​y then f(x)≤Bf(y)f (x) ≤_B f(y)f(x)≤B​f(y).

Let B\mathbb{B}B be the preorders of booleans and N\mathbb{N}N be the preorder of natural numbers. The map B→N\mathbb{B} \rightarrow \mathbb{N}B→N sending false to 17 and true to 24 is a monotone map, because it preserves order.

A monotone map f:P→Qf: P \rightarrow Qf:P→Q preserves joins if ∀p,p′∈P,f(p∨p′)=f(p)∨f(p′)\forall p,p' \in P, f(p\vee p') = f(p) \vee f(p')∀p,p′∈P,f(p∨p′)=f(p)∨f(p′)

For any preorder (P,≤P)(P, ≤_P)(P,≤P​), the identity function is monotone. If (Q,≤Q)(Q, ≤_Q)(Q,≤Q​) and (R,≤R)(R, ≤_R)(R,≤R​) are preorders and f:P→Qf : P → Qf:P→Q and g:Q→Rg : Q → Rg:Q→R are monotone, then (f;g):P→R(f ; g): P → R(f;g):P→R is also monotone.

Let (P,≤P)(P, ≤_P)(P,≤P​) and (Q,≤Q)(Q, ≤_Q)(Q,≤Q​) be preorders. A monotone function f:P→Qf : P → Qf:P→Q is called an isomorphism if there exists a monotone function g:Q→Pg : Q → Pg:Q→P such that f;g=idPf;g = id_Pf;g=idP​ and g;f=idQg;f = id_Qg;f=idQ​. This means that for any p∈Pp ∈ Pp∈P and q∈Qq ∈ Qq∈Q, we have p=g(f(p))p=g(f(p))p=g(f(p)) and q=f(g(q))q =f(g(q))q=f(g(q)).

We refer to ggg as the inverse of fff , and vice versa: fff is the inverse of ggg.

If there is an isomorphism P→QP → QP→Q, we say that PPP and QQQ are isomorphic.

An isomorphism between preorders is basically just a relabeling of the elements.

Galois Connections

Galois connections between preorders PPP and QQQ is a pair of monotone maps f:P→Qf : P → Qf:P→Q and g:Q→Pg : Q → Pg:Q→P such that f(p)≤qiffp≤g(q).f(p) ≤ q iff p ≤ g(q).f(p)≤qiffp≤g(q).

We say that fff is the left adjoint and g is the right adjoint of the Galois connection.

The theory of Galois connections is a special case of a more general theory, the theory of adjunctions.

Example 1: P=Q=3‾P = Q = \underline{3}P=Q=3​

In this case PPP and QQQ are total orders, fff is left adjoint to ggg as long as arrows do not cross.
