2024年開始出現一些背插主板，對DIY來說提供裏極大的便利。B760M-BTF可以視作B760M-Plus的背插版本。背插主板的設計可跳過CPU供電插線和前置IO跳線的繁瑣過程，使裝機過程簡化。

考慮實際遊戲和AIGC需求，高配意義不大，最終選擇配置1：
- 足以搭建本地的txt2img，img2img pipeline。
- 在所有目標遊戲中獲得理想的性能、效果平衡。
- 在wsl2上做一些QLoRA訓練。
