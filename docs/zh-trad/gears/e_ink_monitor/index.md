# 墨水屏顯示器

> 墨水屏主要面向乾眼症人羣，其實也適合神經超敏人羣用於解決視覺誘發性偏頭痛。

從中學時代開始，我就會在受到高頻頻閃、特定空間頻率的圖案或強光刺激後，時不時觸發嚴重偏頭痛、眼眶深部及放射性頭痛，並伴隨自主神經症狀——如噁心、全身乏力。

多年來，眼科和神經科的醫生沒能給我任何有效的診斷和建議，我甚至找到一個非常符合症狀的罕見病，但醫生並不認可，只說這是視覺疲勞。但其他人的視覺疲勞可沒有我這麼痛苦。

在長期、多輪眼科檢查後，排除了種種常規眼疾、各類器質性病變的可能，我認定我的視覺誘發性偏頭痛的根源在於神經殊異性——初級視覺皮層的感覺門控缺陷 + 三叉神經-血管系統的高反應性。
- 大腦無法對輸入的高頻 Temporal Dynamic 信號進行有效的“低通濾波”或“噪聲抑制”，視覺信號在皮層內產生無序的神經元同步化陣發放電。
- 丘腦-皮層環路對高頻節律性光刺激的習慣化（Habituation）能力缺失。正常人羣在面對重複性頻閃時視覺皮層響應會逐漸衰減，而我的視覺中樞表現爲“非習慣化”，持續高強度響應直至神經元能量耗竭與神經系統過載。
- 視覺皮層的高頻過載信號通過皮層-皮層下通路（如枕葉至丘腦及腦幹核團）向下傳導，異常激活三叉神經節及三叉神經脊束核尾側核。進而引發硬腦膜及眼眶周圍血管的無菌性炎症與血管收縮/舒張功能紊亂，釋放 CGRP（降鈣素基因相關肽）等痛覺介質，產生深部眼痛與放射性頭痛。

於是我嘗試用Boox文石13.3墨水屏顯示器+明基ScreenBar屏幕掛燈光源+用於安置掛燈的平板支架，搭建裏一個無屏閃的暖光墨水顯示系統，立杆見影地解決了這一生理上的痛苦。
