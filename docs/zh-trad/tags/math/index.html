  • CAT02: Resources

    第二篇 CAT 筆記討論資源的範疇論形式化，以及如何將一組資源轉化爲另一組資源。內容涵蓋 monoidal preorder（幺半預序）、wiring diagram（接線圖）、monoidal monotone map 和 V-category。

    2024年6月14日 短札 · 約 6 分鐘

    對稱幺半預序

    定義 2.1: 預序 (X,≤)(X,≤)(X,≤) 上的一個 对称幺半结构（symmetric monoidal structure）由兩個成分構成：(i) 一個元素 I∈XI \in XI∈X，稱爲 幺半单位（monoidal unit）；(ii) 一個函數 ⊗:X×X→X\otimes: X \times X \rightarrow X⊗:X×X→X，稱爲 幺半积（monoidal product）。這些成分必須滿足以下性質：

    • 單調性（monotonicity）：∀x1,x2,y1,y2∈X\forall x_1, x_2, y_1, y_2 \in X∀x1​,x2​,y1​,y2​∈X，若 x1≤y1x_1 \le y_1x1​≤y1​ 且 x2≤y2x_2 \le y_2x2​≤y2​，則 x1⊗x2≤y1⊗y2x_1 \otimes x_2 \le y_1 \otimes y_2x1​⊗x2​≤y1​⊗y2​。
    • 單位性（unitality）：∀x∈X\forall x \in X∀x∈X，I⊗x=xI \otimes x = xI⊗x=x 且 x⊗I=xx \otimes I = xx⊗I=x 成立。
    • 結合律（associativity）：∀x,y,z∈X\forall x,y,z \in X∀x,y,z∈X，(x⊗y)⊗z=x⊗(y⊗z)(x\otimes y)\otimes z = x \otimes (y\otimes z)(x⊗y)⊗z=x⊗(y⊗z)。
    • 對稱性（symmetry）：∀x,y∈X,x⊗y=y⊗x\forall x,y \in X, x\otimes y = y\otimes x∀x,y∈X,x⊗y=y⊗x。

  • CAT01: Orders

    CAT 系列第 1 篇，以序理論（order theory）爲完整的範疇論做熱身。內容涵蓋 preorder、meet/join、monotone map 與 Galois connection。

    2024年2月26日 中篇 · 約 18 分鐘

    預序（Preorders）

    從 sets 和 subsets 出發，我們可以把 AAA 與 BBB 之間的 relation 定義爲一個 subset R∈A×BR \in A\times BR∈A×B。

    每個 function 都是一個 relation，滿足 2 個性質：

    1. ∀a∈A\forall a \in A∀a∈A，存在 b∈Bb \in Bb∈B，使得 (a,b)∈R(a,b)\in \mathbb{R}(a,b)∈R
    2. ∀a,b1,b2\forall a, b_1, b_2∀a,b1​,b2​，若 (a,b1)∈R(a,b_1) \in R(a,b1​)∈R 且 (a,b2)∈R(a, b_2) \in \mathbb{R}(a,b2​)∈R，則 b1=b2b_1 = b_2b1​=b2​。

    序（order）、等價（equivalence）、容忍（tolerance）都是 relation。

    function f:A↣Bf: A\rightarrowtail Bf:A↣B 稱爲 injection（單射），如果 ∀a1,a2,b\forall a_1, a_2, b∀a1​,a2​,b，當 (a1,b),(a2,b)∈R(a_1, b), (a_2, b) \in R(a1​,b),(a2​,b)∈R 時，有 a1=a2a_1 = a_2a1​=a2​。

    function f:A↠Bf: A\twoheadrightarrow Bf:A↠B 稱爲 surjection（滿射），如果 ∀b∈B\forall b \in B∀b∈B，存在一個 a∈Aa \in Aa∈A，使得 f(a)=bf(a) = bf(a)=b。
