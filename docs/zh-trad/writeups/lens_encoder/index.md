# 鏡頭與編碼器的同構性

> 相機鏡頭和編碼器呈現驚人的同構性。

## Lens $\cong$ Encoder
相機鏡頭和圖片、音頻的編碼器是同構的，本質都是以高維物理現實爲輸入的降維函數：$$ f: \mathbb{R}^n \to \mathbb{R}^d, d \ll n$$

鏡頭將無窮光場壓縮成相機傳感器上的像素矩陣：
```
 3D Scene
    ↓
   Lens
    ↓
2D Sensor Image
```

Encoder將無限物理現實的某種人工採樣壓縮成低維向量：
```
 Waveform
    ↓
  Encoder
    ↓
 Embedding
```

## 像散&彗差 $\cong$ 各向異性

我新買了一個rf28mm f2.8 pancake，發現它用了形狀特殊的非球面樹脂鏡片，樹脂材質天然不均勻，因此有像散（垂直和水平方向分辨率不同）和彗差（斜向誤差）。這個過程簡直和表徵學習中模型“材質”的天然不均勻以及模型輸出的天然各向異性有一模一樣的結構。我意識到人類的種種活動，在更高維存在眼中或許都是一回事。佳能的光學設計師設計鏡頭，和我嘗試做一個audio encoder，本質上都是要把高維物理現實經過一個非線性變換投射到一個低維表示上。

樹脂鏡片的不均勻性導致了最終輸出中必然存在各向異性。我們的各種表徵模型也一樣，輸出的embedding幾乎一定具有強烈的各向異性性。

## 克服各向異性
一個獨立於任何具體下游任務的優化目標自然而然地出現了——各向同性。光學和ML工程師都在克服各向異性，試圖做到各向同性。

- 如果光學工程師換更高級的玻璃鏡片，用上種種補償元件，則可接近各向同性。最終像平面上就不會因彗差出現彗星形光斑和縱向橫向清晰度不同的問題。從而讓鏡頭可以冠上紅圈L頭之名。
- 如果ML工程師用SIGReg正則等手段約束模型輸出各個維度更均勻的embeddings，那麼這些embeddings的應用場景就更泛化，不侷限於loss+sampler設計時關注的單一supervised場景，也能用在跨模態對齊、聚類等場景，從而讓模型可以冠上foundation model之名。

## 適應各向異性
另一個思路則是接受各向異性的事實，利用它降本。相機矯正算法/固件工程師和大規模向量檢索系統的HPC工程師都在適應各向異性。

- 比如佳能相機的數字矯正技術和鏡頭設計就是相輔相成的，rf28 2.8用了樹脂鏡片反而可以節省成本。
- 又如Google的工程師接受了大多數模型的embedding不那麼“圓”的事實，提出了scann各向異性量化，做到了更激進的ANNS性能優化。

這種思路固然在工程上有效，卻缺乏魯棒性和泛化性。一旦失去機內校正（假設我們可以將它強行移植到一個奇怪的機身上），rf28mmf2.8的成像就會顯著劣化。一旦用在非ANNS場景，各向異性量化也無法發揮出向量檢索時的最小化誤差。
