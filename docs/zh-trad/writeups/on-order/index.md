# 論秩序

> 秩序，湧現自耗散結構的自組織。

---

LLMS index: [llms.txt](/llms.txt)

---

秩序在耗散結構的自組織中湧現，這一現象無所不在，流體熱力學中的瑞利-貝納德對流[^11]（天空中規則的雲[^5]、太陽米粒組織[^13]、巨人岬六角石柱[^12]、地幔對流[^14]）、化學系統中的貝洛索夫-扎博廷斯基反應[^10]，以及我們熟知的一切——氣候、城市、火焰、爆炸、股市、交通、蜂羣、生態系統、新陳代謝、生命、意識。

![stone](https://wujipeng.com/img/stone.webp)

耗散結構，即與環境持續交換物質和能量，維持某種遠離平衡態的穩態系統。耗散結構的產生源於輸入和耗散，當能量或物質流入一個系統時，如果存在適當的機制來消散多餘的能量，那麼它可能會導致局部的秩序增加或者規律的形成。隨着耗散的持續，起初不存在的複雜度，或者說“精緻度”，就在耗散系統中誕生了——新的行爲、結構、圖景應運而生，自發組織，自動裝配，自主運行。

平衡態下，系統各處可測的宏觀物理性質均勻，系統內部內有宏觀不可逆過程，遵守熱力學第一定律（內能增量=吸收的熱量-對外做功）、熱力學第二定律(系統自發熵增）、玻爾茲曼有序性定理（溫度爲T的系統中內能爲E的子系統的比率爲e-E/kT）。近平衡態系統處於距離平衡態不遠處的線性區，遵守昂薩格倒易關係（用一組公式描述系統輸運過程中各種流和力的關係）和最小熵產生原理（給定邊界條件組織系統達到平衡態時，系統落入最小耗散，即最小熵產生的態）。

所謂遠離平衡態，是相對平衡態和近平衡態而言，系統內可測物理性質極不均勻的狀態，這種狀態下系統的熱力學行爲違逆最小熵產生原理，走向高熵產生、宏觀有序的狀態。

與平衡態熱力學相比，關於遠離平衡態的耗散結構的理論和實踐還都非常粗淺簡陋。

物理學、生物學、化學、甚至社會科學，在遠離平衡態和自組織領域之外駐足不前，有序現象背後蘊藏着真理寶庫而人類不得入。George M. Whitesides在"Reinventing Chemistry"一文中展望未來的化學學科和化學工業時[^1]，指出90年代後化學界的歷史旋律從一個又一個“發現”，變成“迭代”和“提升”，而未來，“atoms, molecules, and reactions”不足以概括化學，未來的化學應該涉足生命起源，解釋生命的分子基礎，研究海洋、大氣、火焰等耗散系統，嘗試解答大腦是如何運作的，理解微生物組（microbiome）對健康的影響，以及用理性指導藥物設計等。
