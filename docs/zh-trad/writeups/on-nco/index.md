# 非凸優化

> 非凸優化(non-convex optimization)，more like art

---

LLMS index: [llms.txt](/llms.txt)

---

凸優化收斂時間一般是polynomial的，線性規劃和最小二乘就是凸優化的特例。

非凸優化non-convex optimization是一種至少np-hard的問題，不存在通用解法。想要確定問題是否有解，局部最優是否全局最優，或目標函數是否有界都會隨着變量和約束數目指數爆炸blow up，局部優化手段對算法參數敏感，又高度依賴initial guess，這使局部非凸優化more-art-than-technology，相比而言線性規劃是毫無art可言的。

深度神經網絡作爲通用函數擬合器，最重要的作用是擬合非凸函數，因爲複雜問題一般不可以用凸函數擬合。ChatGPT這類生成式模型就是對target和input間互信息的非凸優化。怎麼訓好模型，目前依然是一個art。

隨機梯度下降stochastic gradient descent(SGD)被證明可以收斂於凸函數、可微和利普希茨連續函數，但還不能確定在非凸函數上的效果，SGD收斂緩慢，還不一定達到局部最優，更不一定達到全局最優。如果選擇一個足夠靠近全局最優的點，或許可以用SGD收斂到全局最優，但這一方面耗時間，另一方面只適用於特殊場景。對於深度神經網絡來說，一旦陷入錯誤的局部最優，就要用不同的初始化配置或加入額外的梯度更新噪音。如果遇到鞍點，則需找到海森矩陣或計算下降方向。如果陷入低梯度區域，則需batchnorm，或使用relu做激活函數。如果因高曲率而使得steps過大，則應使用adaptive step size或限制梯度step尺度。此外，如果超參有問題，還需要用各種超參優化的方法。總之，目前深度學習的NCO還是處於art的階段。
