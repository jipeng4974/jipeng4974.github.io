# 知識是現實的Embedding

> 現實無限廣博，無限深邃，將其嵌入我們有限的認知空間後，就形成了知識。

現實有無限維度，現實的背後還有潛在現實，結構的邊緣會湧現出新的深層結構。

人類對現實的感知、認知、理解，本質上是將高維現實投射到一個低維表示上，這種低維表示在統計學和機器學習中被稱爲embedding（嵌入），沒錯，知識就是將現實在人類有限的認知空間的一個嵌入，緊湊、淺薄且片面。

舉個具體的例子，人眼觀察到的彩虹呈現七色。

但這只是對無限廣博的現實的最初觀察，是最直觀的認知。

人類通過對人體生理學的研究，發現七色感知是一個更深層的潛在現實的湧現結構：多種光感受器的疊加反應。

人類顏色感知系統對紅綠藍敏感的三種光感受器，疊加反應產生的三個峯和四個谷決定了人類能感知到7種顏色。
![color](https://wujipeng.com/img/color.png)

鳥類由於擁有對紫外線敏感的光感受器，就能感知到9種顏色，因此可以看到九色彩虹。

無論人類的七色彩虹還是鳥類的九色彩虹，都只是知識（或者說embedding），而不是現實。

人類通過數學工具和電磁學研究，進一步認識到光譜是連續的，包括無線電波、微波、熱、紅外線、可見光、紫外線等。

這接近現實了嗎？不，這依然只是淺薄的embedding。。

人類通過量子物理學的研究，發現現有的電磁學依舊是一個更深層的潛在現實的湧現模型——電磁波是量子粒子流的一種表現形式：光子。

光子的認知，折射出更復雜的現實，因爲一個光子同時擁有無限的位置和頻率，直到被觀察到才能確定其位置或能量，需用海森堡不確定性原理、薛定諤方程來描述，這依舊不是真理，不是終極，仍然是在現實之上所施加的結構(structure imposed upon reality)。

類似地，現實中的一首歌曲，看似簡單平凡，實際上卻擁有無窮維度，我們可以從任意一個角度去理解它，將它嵌入到任意一個向量空間。

假設用戶手機的傳感器捕捉了一段音頻，將其上傳到平臺上，消重（時頻圖的mask特徵）、指紋(時頻圖的landmark特徵)、翻唱（淺層cnn）、哼唱（whisper大模型）、多模態大模型應用分別捕捉了這段音頻的某種特徵，產生了不同層次的知識（embedding），理解愈發深邃，愈發不精確，應用也就愈發靈活，愈發貼近人類思維。

後端的消重服務或指紋服務將表示音頻的信號採樣數據通過fft計算得到時頻圖，再基於時頻圖提取某種mask特徵或landmark特徵，用於直接刻畫其能量分佈特徵，然後與音頻特徵庫裏存着的現有特徵做對比就可以找到匹配的音頻，這就是音頻消重和指紋識別的過程：對信號做簡單數學處理，生成的就是高度特化、具體、緊湊、確定、可解釋的知識，表示這種知識的embedding或不具有抗噪性（mask特徵），或具有少許抗噪性（landmark特徵），但無論如何都只適用於原曲匹配，不知何爲翻唱，何爲remix，何爲二創，何爲串燒。

翻唱識別服務能通過一個學習了歌曲旋律的神經網絡對音頻信號進行處理，產出一定程度上表達旋律特徵的embedding，將曲庫裏的翻唱embedding存入向量數據庫，通過KNN/ANN召回的結果往往不限於原曲，還能容忍變調、音色上的改變。

哼唱識別服務可以基於Whisper這樣的音頻大模型實現，這種深層網絡學習了人類的自然語言，因此對音頻信號處理時，提取了表達歌詞信息的embedding。基於這樣的embedding，可以在跑調非常嚴重，且沒有伴奏的情況下，依然能識別出用戶在哼什麼歌。

考慮未來的多模態大模型，更是可以直接將embedding存在transformer的ffn層，不必藉助外部的向量數據庫或倒排索引，直接在模型內部刻畫embedding之間的複雜關係，讓更多概念之間產生關聯：識別出歌曲的意境、歌唱者的情緒、歌詞內容的圖片，甚至聯繫用戶交互的上下文，衍生出更客製化、場景相關的輸出。

人工智能領域用transformer簡單搭建的大模型擁有出人意料的邏輯能力，昭示着人類意識的本質或許原本就極端膚淺：將知識內化、知識關聯後，用天生的腦回路做貝葉斯推理，就產生了邏輯，誠然現有的結構遠不如人腦高效，但有和無的界限已經被突破。
