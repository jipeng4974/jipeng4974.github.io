CAT01: Orders

CAT 系列第 1 篇，以序理論（order theory）爲完整的範疇論做熱身。內容涵蓋 preorder、meet/join、monotone map 與 Galois connection。

預序（Preorders）

從 sets 和 subsets 出發，我們可以把 AAA 與 BBB 之間的 relation 定義爲一個 subset R∈A×BR \in A\times BR∈A×B。

每個 function 都是一個 relation，滿足 2 個性質：

  1. ∀a∈A\forall a \in A∀a∈A，存在 b∈Bb \in Bb∈B，使得 (a,b)∈R(a,b)\in \mathbb{R}(a,b)∈R
  2. ∀a,b1,b2\forall a, b_1, b_2∀a,b1​,b2​，若 (a,b1)∈R(a,b_1) \in R(a,b1​)∈R 且 (a,b2)∈R(a, b_2) \in \mathbb{R}(a,b2​)∈R，則 b1=b2b_1 = b_2b1​=b2​。

序（order）、等價（equivalence）、容忍（tolerance）都是 relation。

function f:A↣Bf: A\rightarrowtail Bf:A↣B 稱爲 injection（單射），如果 ∀a1,a2,b\forall a_1, a_2, b∀a1​,a2​,b，當 (a1,b),(a2,b)∈R(a_1, b), (a_2, b) \in R(a1​,b),(a2​,b)∈R 時，有 a1=a2a_1 = a_2a1​=a2​。

function f:A↠Bf: A\twoheadrightarrow Bf:A↠B 稱爲 surjection（滿射），如果 ∀b∈B\forall b \in B∀b∈B，存在一個 a∈Aa \in Aa∈A，使得 f(a)=bf(a) = bf(a)=b。

function f:A↣≅Bf: A \overset{\cong} \rightarrowtail Bf:A↣≅​B 稱爲 bijection（雙射），如果它既是滿射又是單射。

集合 XXX 上的 identity function 記作 idXid_XidX​，即雙射函數 idX(x)=xid_X(x) = xidX​(x)=x。

AAA 上的一個 partition（劃分）無非就是到另一個集合 PPP 的滿射：A↠PA \twoheadrightarrow PA↠P。

我們可以給 partitions 排序：A↠P1A \twoheadrightarrow P_1A↠P1​，A↠P2A \twoheadrightarrow P_2A↠P2​。如果存在一個 function P1→P2P_1 \rightarrow P_2P1​→P2​ 使下圖交換：A↠P1→P2A \twoheadrightarrow P_1 \rightarrow P_2A↠P1​→P2​，則稱 P1⩽P2P_1 \leqslant P_2P1​⩽P2​。

因此 A↠AA \twoheadrightarrow AA↠A 是最小的 partition，而 A↠1‾A \twoheadrightarrow \underline{1}A↠1​ 是最大的 partition。

preorder（預序）是

  1. 一個集合 SSS，以及
  2. 一個關係 ≤ ⊆S×S≤ \: \subseteq S \times S≤⊆S×S1

並滿足 2 個性質：

  1. S≤SS ≤ SS≤S。2
  2. ∀S1\forall S_1∀S1​、S2S_2S2​、S3S_3S3​，若 S1≤S2S_1 ≤ S_2S1​≤S2​ 且 S2≤S3S_2 ≤ S_3S2​≤S3​，則 S1≤S3S_1 ≤ S_3S1​≤S3​。3

preorder 就是任意兩個對象之間至多隻有一個 morphism 的 category。稍微複雜一點的說法是：preorder 是一種 Bool-enriched category。

Meet 與 Join

序（order）催生了 meets 和 joins。

將 AAA 與 BBB 做 join，記作 A∨BA\vee BA∨B，得到的是同時大於 AAA 和 BBB 的最小 partition。即 A≤(A∨B)A ≤ (A\vee B)A≤(A∨B) 且 A≤(A∨B)A ≤ (A\vee B)A≤(A∨B)。並且對任意 C，若 A≤CA ≤ CA≤C 且 B≤CB ≤ CB≤C，則 (A∨B)≤C(A\vee B) ≤ C(A∨B)≤C。

形式化地說。設 (P,≤)(P, ≤)(P,≤) 是一個 preorder，A⊆PA \subseteq PA⊆P 是一個 subset。若元素 p∈Pp \in Pp∈P 滿足以下條件，則稱 ppp 爲 AAA 的一個 meet：

  1. ∀a∈A\forall a\in A∀a∈A，都有 p≤ap≤ ap≤a4，並且
  2. 對所有滿足"對任意 a∈Aa\in Aa∈A 都有 q≤aq≤ aq≤a“的 qqq，都有 q≤pq≤ pq≤p5。

記作 P=∧A=∧a∈Aa=a1∧a2∧...∧anP = \wedge A = \underset{a\in A}{\wedge} a = a_1 \wedge a_2 \wedge ... \wedge a_nP=∧A=a∈A∧​a=a1​∧a2​∧...∧an​

類似地，若滿足以下條件，則稱 ppp 爲 AAA 的一個 join：

  1. ∀a∈A\forall a\in A∀a∈A，都有 a≤pa≤ pa≤p6，並且
  2. 對所有滿足"對任意 a∈Aa\in Aa∈A 都有 a≤qa≤ qa≤q“的 qqq，都有 p≤qp≤ qp≤q7。

此時記作 P=∨A=∨a∈Aa=a1∨a2∨...∨anP = \vee A = \underset{a\in A}{\vee} a = a_1 \vee a_2 \vee ... \vee a_nP=∨A=a∈A∨​a=a1​∨a2​∨...∨an​

例 1：布爾值 B\mathbb{B}B={T,F}$ 的真值表。

例如，{T,F}(F≤T)\{T,F\}(F \leq T){T,F}(F≤T) 的兩兩 meets 表恰好就是初等邏輯中 AND 的真值表。類似的二元 join 計算會生成 OR 的真值表。

例 2：冪集 (P(x),≤)(P(x), ≤)(P(x),≤)。

例 3：(N,∣),a≤b(\mathbb{N}, |), a ≤ b(N,∣),a≤b 當且僅當 a∣ba|ba∣b

1 整除所有數，所以我們從 1 開始。這裏 ∧\wedge∧ = gcd，∨\vee∨ = lcm。

例 4：meet/join 可能不止一個。

這張 Hasse 圖給出了一個 preorder，其中 ccc 和 ddd 都是 AAA 的 meets。我們有 c≤dc≤ dc≤d 且 d≤cd≤ cd≤c，所以 c≅dc \cong dc≅d，即 ccc 與 ddd 是 isomorphic（同構）的，這一點後文會講到；不過一般來說，我們把它們當作相等也不會遇到什麼麻煩。

例 5：meet 或 join 可能不存在。

顯然，事物並不總是有下界或上界。也可能存在多個下界/上界，但這些下界/上界之間不可比較。

縱觀這些例子，許多熟悉的事物——無論是 gcd/lcm、max/min、limits/colimits，還是 intersection/union——都可以用這個相當簡單的泛性質（universal property）來刻畫。

事物可以由泛性質來刻畫，這一想法意味着我們現在離範疇論更近了。

單調映射（Monotone Maps）

Preorders 自身之間也可以相互關聯。monotone map 就是 preorders 之間保持結構的映射。

preorders (A,≤A)(A, ≤_A)(A,≤A​) 與 (B,≤B)(B, ≤_B)(B,≤B​) 之間的 monotone map 是一個 function f:A→Bf : A \rightarrow Bf:A→B，使得對所有元素 x,y∈Ax, y ∈ Ax,y∈A，若 x≤Ayx ≤_A yx≤A​y，則 f(x)≤Bf(y)f (x) ≤_B f(y)f(x)≤B​f(y)。

設 B\mathbb{B}B 爲布爾值的 preorder，N\mathbb{N}N 爲自然數的 preorder。把 false 映到 17、把 true 映到 24 的映射 B→N\mathbb{B} \rightarrow \mathbb{N}B→N 是一個 monotone map，因爲它保持了序。

若 ∀p,p′∈P,f(p∨p′)=f(p)∨f(p′)\forall p,p' \in P, f(p\vee p') = f(p) \vee f(p')∀p,p′∈P,f(p∨p′)=f(p)∨f(p′)，則稱 monotone map f:P→Qf: P \rightarrow Qf:P→Q 保持 joins。

對任意 preorder (P,≤P)(P, ≤_P)(P,≤P​)，恆等函數都是單調的。 若 (Q,≤Q)(Q, ≤_Q)(Q,≤Q​) 和 (R,≤R)(R, ≤_R)(R,≤R​) 是 preorders，且 f:P→Qf : P → Qf:P→Q 與 g:Q→Rg : Q → Rg:Q→R 都是單調的，則 (f;g):P→R(f ; g): P → R(f;g):P→R 也是單調的。

設 (P,≤P)(P, ≤_P)(P,≤P​) 與 (Q,≤Q)(Q, ≤_Q)(Q,≤Q​) 爲 preorders。若存在一個 monotone function g:Q→Pg : Q → Pg:Q→P 使得 f;g=idPf;g = id_Pf;g=idP​ 且 g;f=idQg;f = id_Qg;f=idQ​，則稱 monotone function f:P→Qf : P → Qf:P→Q 爲一個 isomorphism（同構）。這意味着對任意 p∈Pp ∈ Pp∈P 和 q∈Qq ∈ Qq∈Q，都有 p=g(f(p))p=g(f(p))p=g(f(p)) 且 q=f(g(q))q =f(g(q))q=f(g(q))。

我們稱 ggg 爲 fff 的逆，反之亦然：fff 是 ggg 的逆。

若存在一個 isomorphism P→QP → QP→Q，則稱 PPP 與 QQQ 是同構的（isomorphic）。

preorders 之間的同構，基本上只是對元素的重新標記（relabeling）。

Galois 連接（Galois Connections）

preorders PPP 與 QQQ 之間的 Galois connections 是一對 monotone maps f:P→Qf : P → Qf:P→Q 和 g:Q→Pg : Q → Pg:Q→P，滿足 f(p)≤qiffp≤g(q).f(p) ≤ q iff p ≤ g(q).f(p)≤qiffp≤g(q).

我們稱 fff 爲左 adjoint（左伴隨），g 爲該 Galois connection 的右 adjoint（右伴隨）。

Galois connections 的理論是一個更一般的理論——adjunctions（伴隨）理論——的特例。

例 1：P=Q=3‾P = Q = \underline{3}P=Q=3​

此時 PPP 和 QQQ 都是全序（total order），只要箭頭不交叉，fff 就是 ggg 的左伴隨。

例 2：Z→f3×□R\mathbb{Z} \xrightarrow[f]{3\times\square} \mathbb{R}Z3×□f​R，R→g⌊□/3⌋Z\mathbb{R} \xrightarrow[g]{\lfloor\square/3\rfloor} \mathbb{Z}R⌊□/3⌋g​Z

也就是說我們有 5→f3×□155 \xrightarrow[f]{3\times\square}1553×□f​15，13.3→g⌊□/3⌋413.3 \xrightarrow[g]{\lfloor\square/3\rfloor}413.3⌊□/3⌋g​4。

由於 3n≤x3n ≤ x3n≤x 當且僅當 n≤⌊x/3⌋n ≤ \lfloor x/3\rfloorn≤⌊x/3⌋，所以 fff 是 ggg 的左伴隨。

歸根結底，我們可以斷言：monotone map fff 是左/右 adjoint，當且僅當它保持 joins/meets。
