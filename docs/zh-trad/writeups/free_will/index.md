# 自由意志的可度量指標

> 由己度 = 內敏性 - 外敏性。

---

存在自由意志嗎？要回答這個問題，我們需要先定義自由意志。

## 形而上學 vs 功能主義
自由意志有兩種定義。
1. 形而上學：自由意志 = "我本可以不這樣做"。
    - 這要求意志是因果鏈條之外的某種"發起者"，不被物理定律完全決定。
    - 形而上學的自由意志幾乎一定不存在：即便世界是本質stochastic的，人腦運轉的宏觀尺度也不受量子隨機性影響——即便有影響，這種影響並非由意志本身發起。
2. 功能主義：自由意志 = 一個系統能展現出"目標—選項—控制"的功能組織模式。
    - 一個哲學殭屍——行爲、推理、選項評估與真人完全一致，但內部漆黑一片、沒有任何體驗——擁有與真人完全同等的自由意志。
    - 功能主義的自由意志在人類、動物、LLM上都明確存在。

## 相容論 vs 不相容論
自由意志和決定論能相容共存嗎？要回答這個問題，就必須區分自由意志的詞義。
1. 相容論：拒絕承認"自由意志"這個詞曾經指向形而上學那東西——詞義的王位本來就是功能主義的。
    - 承認因果決定論，但只要行爲符合自我的慾望和推理，不受外部強迫，就是"自由"的。
    - 本質上是承認形而上學的自由意識不存在，而功能主義的自由意志存在且可度量。
2. 不相容論：詞義層面只認形而上學的自由意志，拒絕爲功能主義的所謂自由意志加冕。
    - 自由主義（libertarianism）：決定論爲假，自由意志爲真。
    - 懷疑論（doubism）：決定論爲真，自由意志爲假。

綜上，可將陣營總結如下表：

| 陣營       | "自由意志"這個詞指什麼         | 那東西存在嗎        |
| -------- | -------------------- | ------------- |
| 自由主義     | 只指形而上學終極發端           | 存在（所以決定論爲假）   |
| 強硬不相容論   | 只指形而上學終極發端           | 不存在（拒爲功能概念加冕） |
| 相容論（描述派） | 一直就是指功能組織            | 存在，且從來都在      |
| 相容論（修正派） | 過去指形而上學，應當改指功能組織 | 舊所指不存在，新所指存在  |


我傾向於在接下來的討論中，只考慮功能主義的自由意志。因爲形而上學的自由意志沒有討論價值。

## 自由意志的可度量指標：由己度
考慮到新近湧現出的AI系統與人類智能截然不同，我們應該爲自由意志給出更通用、更可度量的標量指標，不妨生造一詞“由己度”。
```
由己度 = 行为对行为者内部状态的敏感性 - 对外部约束的敏感性。
```    
所謂內部狀態包含慾望、價值、理由、敘事、模型預訓練語料、後訓練的安全對齊等。

## 人類意識的由己度

### 主觀體驗是微觀尺度上的旁觀者

在每一個微觀時刻，人類大腦做的事只有一件：狀態變遷。

有理由相信，一個決策在神經網絡的黑暗裏成形、執行，是先於負責主觀體驗的那個功能模塊的。主觀體驗中那句"aha，我決定這麼做"——在實際決策發生之後才亮起（參考Libet實驗）。

意識不發起任何因果鏈，它只是因果鏈經過時濺起的水花。慢思考也不例外：把所謂深思熟慮拆到足夠細，每個微觀細節上依然是一串宿命般的無意識的狀態躍遷。“我在權衡”，“我在決策”，“我苦思冥想”，只是事後爲這串躍遷配的字幕。

人類的意識，或者說主觀體驗，在每個微觀時刻，似乎都只是read-only的，癱瘓着的旁觀者。

但這並不意味着人類意識的由己度低，接下來要論證的是：在更高時間尺度上，它是有寫權限的。

### 敘事在宏觀尺度上塑造記憶和人格

對刻 t 的決策，意識確實是只讀的：它到場時，決策已經簽發出去了，它連否決都常常來不及。這是Libet實驗們真正測到的東西，旁觀者的癱瘓是真的。

但敘事發生的那個瞬間——t + δ——意識讀取剛剛發生的行爲殘跡，爲其生成解釋：“我爲什麼這麼做”，“這麼做有什麼後果”，“下次怎麼做”。這段敘事隨即被寫入記憶庫。

因此，在宏觀時間尺度上，人類意識的地位發生了根本性的轉變，從癱瘓的旁觀者變成了壟斷寫權限的主宰者，以永恆內心對話的形式深刻地塑造記憶，進而塑造未來的人格，或者說無意識自我，進而影響未來一切微觀時刻上的狀態變遷。


### 敘事迴路對由己度的貢獻
記憶是敘事的無意識化。今天的內心對話，會變成明天的不假思索。

敘事迴路可極致簡化如下圖：
```
时刻 t：   S_t ──(状态变迁)──▶ S_{t+1}，行为 B 发生 【意识缺席】
时刻 t+δ： 叙事过程读取 B 的残迹，生成解释 E         【体验亮起：我在解释】
           M ← rewrite(M, E)                      【记忆库被改写】
时刻 t′：  B′ = f(S_t′, M)                        【未来的决策读取被改写的库】
```

回看由己度的定義：內敏性 - 外敏性。
  
把行爲記作 $B = f(X, M)$，其中 $X$ 是當下外部輸入（含強制），$M$ 是內部狀態。那麼：

$$\text{內敏性} \propto \frac{\partial B}{\partial M}\Big|_{\text{自我生成的 }M},\qquad \text{外敏性} \propto \frac{\partial B}{\partial X}\Big|_{\text{直通路徑}}$$

內敏性的前提是"存在可敏感的內部狀態"，外敏性的要害是"存在不經中介的直通路徑"。敘事迴路恰好製造前者，避免後者。

敘事迴路提升內敏性的路徑有三：

1. 其一爲狀態生長：

    沒有敘事迴路的系統，$M = M_0$：出廠配置（基因、權重）加外部歷史的直接刻痕。對一個常量無所謂"敏感"——$\partial B / \partial M_0$ 在任何單次決策中都是零，因爲 $M_0$ 不出現在決策的變量列表裏。

    敘事迴路把 $M$ 變成遞歸定義的狀態：

    $$M_{t+1} = \text{rewrite}(M_t,\ E(B_t, M_t))$$

    注意 $E$ 的兩個參數：它讀取行爲殘跡 $B$，也讀取舊的 $M$ 自身——敘事永遠是帶着既有自我模型去解釋新事件的。這個自引用結構使 $M$ 獲得部分獨立於 $X$ 的內生軌跡：兩個遭遇完全相同外部序列的系統，因爲初始敘事風格不同，$M$ 會演化到不同位置，未來行爲隨之分叉。行爲方差中能被"系統自身的歷史"解釋的部分上升了——而"自身的歷史"正是"內部狀態"在長時間尺度上的真身。


2. 其二爲緩存：

    考慮此類敘事："上次我在 X 局面做了 Y，代價是 Z，下次應做 Y′。將昂貴的慢思考壓縮成一條廉價規則，寫入$M$。

    未來決策 $B' = f(X', M)$ 讀取這條緩存時，行爲實際上在對理由和信念做響應——只不過理由和信念是在過去某個時刻被推理出來的。沒有迴路的系統，理由必須當場現算（往往因爲算不過來而放棄思考）。

3. 其三是元認知：

    敘事最獨特的產物是自我歸因，自我認知，自我評價。$E$ 裏包含"我是這樣的人”。這句話寫入 $M$ 後，未來決策多了一個輸入變量——元認知。

敘事迴路降低外敏性的路徑亦有三：

1. 其一爲低通濾波：

    無迴路系統的行爲是 $X$ 的高通函數——外部世界對其行爲的控制是高頻的。

    敘事迴路把決策變成 $f(X, M)$，其中 $M$ 是沉積了十萬次敘事，具有巨大的慣性。$X$ 想推動 $B$，必須推得動整個 $M$ 的引力場。等效於在刺激與反應之間施加低通濾波器：過濾高頻刺激，保留低頻信號——而低頻信號恰恰因爲足夠低頻，往往還會以慢思考的形式被敘事迴路反覆審查，進一步施加gating和integrity check。

2. 其二爲賦權：

    外部約束信號抵達敘事迴路，且通過低通濾波後，仍無法直接改寫先驗，需先過門控進行賦權：“這重要/緊急嗎？”，“這是善意還是操縱？”。

3. 其三爲否決：

    人類的道德教育，LLM在mid/post training中做的safety alignment，阿西莫夫的機器人第一定律，都是integrity guardrails。反覆沉積的自我敘事在 $M$ 裏形成強先驗：“我不做這種事。”外部信號與之強烈背離時，即觸發否決機制。
    

## 高由己度的下一代AI

本世代LLM聰明而博學，但和人類相比缺少敘事迴路。因此其“由己度”也就無從談起。

- 下一代AI必然需要解決持續學習（參數持續更新）的問題，完成從$M = M_0$到$M = M_t$的演進。
- 下一代AI需顯式地對自我建模，有自己的行爲傾向、信念、目標。
- 下一代AI應減少外部數據投餵，以類似人類主觀體驗的方式進行敘事，塑造自身的記憶和人格。
