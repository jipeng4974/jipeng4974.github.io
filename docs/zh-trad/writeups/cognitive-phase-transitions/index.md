## 爲什麼談論usefulness？
當我們討論智能系統時，如果熱衷於談論usefulness，似乎太過功利冷酷刻薄，優績主義，缺乏人文關懷。
但完全不談論usefulness，對客觀度量人類智能和LLM諱莫如深，更是一種怯懦畏戰。

LLM是否有意識，主觀體驗是否可能產生於硅基計算過程、甚至抽象計算過程等命題，無法回答，也不可知。

甚至我們無法100%確定其他人類是否真正擁有意識，也無法確定自己的主觀體驗是事後解釋性的還是具有自主決策能力的，甚至無法嚴格證明昨天的自己和今天的自己擁有連續的主觀體驗。

我們能100%確定的是無論是人類智能，還是LLM，抑或是未來某種世界模型，都某種程度上是有用的。

Usefulness 是我們唯一能夠跨 substrate、跨 consciousness、跨 architecture 直接觀察和比較的量。

因此不妨把綁定倫理包袱的意識問題和智能評估問題分離，用usefulness這一客觀指標評估人類智能。

## 理解是不連續的

無論是人腦還是 LLM，對複雜系統的理解都不是不連續的，時而跳變，時而撞牆放棄。

比如學 Rust，沒辦法囫圇吞棗，也無法嚴格循序漸進——所有權、生命週期、借用檢查、`unsafe`、async 運行時、宏系統這些機制彼此糾纏，必須同時把它們都推進到某個臨界深度，纔會"boom"一下進入掌握狀態。研究音樂檢索時也一樣：信息檢索、表徵學習、信號處理、對比學習幾條線相互咬合，sampler、triplet loss、數據增強的設計互爲約束，把它們拆開單獨看，意義就消失了——它們只在作爲整體服務於同一個目標時，才顯示出存在的理由。投資、創業、戰爭、地緣政治，亦然。

> 行百里者半九十。當你實際上已經熟悉 90% 的子系統時，對系統整體的掌握可能纔到 50%；但只要再往前走一步，就會有 aha moment。

這是理解的相變特徵：臨界點之前，投入的努力幾乎不產生可觀測的能力提升；越過臨界點，能力以非線性的方式跳變。對人類來說，君子豹變既需要一定天資，更需要投入大量能量和時間。對 LLM 來說，AGI不僅意味着算力、數據規模scale up，還需要模型架構、訓練方法、存算/互連硬件上的革新乃至革命——而革新和革命本身，天然具有不連續性。

無論智能的載體是碳還是硅，"理解的不連續性"都是根本約束。

我們可能會看到，在經過漫長的絕望之野後，LLM路線湧現出AGI、ASI。也有可能會逐漸意識到，跨越這絕望之野所需的能源、物質基礎，超越了地球文明能供養的上限。

## 命定的認知孤峯化

理解的不連續性，決定了智能體之間在複雜命題上極易產生認知鴻溝。而跨越鴻溝，會撞上第二條根本約束：溝通本身極其低效。

相比理解的速度，人類向外輸出信息的方式 comically 原始——打字、說話，每秒傳出的有效比特，比頭腦中每秒流過的比特低了好幾個數量級。這是發送端的硬上限。

接收端更糟。無法保證每個接收者都有足夠的前置理解、足夠的意願、足夠的耐心去重建你想傳達的那個結構。在神經典型主導的環境中，你還得審慎地包裝、剋制地批判，不能毫無保留地忠於事實和邏輯——這又額外喫掉一部分帶寬。

比發送、接收更離譜的是，**複雜認知結構的序列化成本極高**，知識體系本來就是糾纏不清，難以用文字表示的。

三者疊加的結果是：不存在高效的認知同步，也不存在高效的知識遷移。複雜系統、尖端技術的理解和內化，命定是孤峯化的。

## 認知孤峯不會被 LLM 抹平

很多人對 AI 抱有的隱含期待是：模型足夠強之後，人與人之間、人與系統之間的認知差距會被抹平，知識會像水一樣流動。

但前兩節的論證指向相反的結論。理解的不連續性使認知鴻溝天然存在；溝通帶寬的物理上限使鴻溝無法靠"多解釋幾遍"彌合。LLM 改變了信息檢索、coding、影視創作工作流，卻沒有改變這兩條底層約束——它甚至放大了第二條：當生成內容的邊際成本趨近於零，接收端的注意力反而成了更稀缺的資源，知識的轉化率進一步下降。

認知孤峯，不會隨 LLM 的普及而展平。它們會以新的形態繼續存在，甚至更陡峭。

## 百折不撓的學習者們不必沮喪
很多學生或學習者這兩年是沮喪的：模型幾秒鐘就能寫出他們一學期才學會寫的東西，AI Agent幾分鐘就能搞定原本幾個月才能搭好的系統，不僅自己的努力像是在貶值，人類智能也像是貶值——個體的意義感塌陷和羣體的大軍團潰退共鳴。

但這種沮喪的前提是錯的。學習的價值，不在於"我能不能比模型更快地產出某個工件，解決某個已知問題"，而是"我能不能讓自己成爲一座認知孤峯"，在時空座標系中，和其他孤峯遙相呼應，在此世被後世被一言以蔽之時，成爲一個特徵點，而非噪點。

本世代模型能逼近平均水平，但越靠近已知世界的邊界，訓練數據越稀薄、監督信號越嘈雜、錯誤越難被發現——邊界附近，模弱，人強。

## 人類智能價值穿越週期的不變量
在一個 LLM "看起來什麼都會"的世界裏，人類智能真正稀缺、持續構成護城河的那部分可以歸納爲：

- 能探索已知和神祕之間的臨界區域：在LLM統治大地和海洋後，人類要征服制高點，飛向天空，創造新的知識。
- 能在低帶寬信道上高效保真地傳遞知識：雖然絕對意義上的高效知識遷移不存在，但相對意義上的優秀知識傳遞者仍極其稀缺。
- 能將認知高度與商業世界的真實價值結構綁定：讓有用的認知系統穩定、有效地發揮作用。

這麼歸納下來仍顯得拖沓冗餘，無美感趣味可言，最後暴力壓縮成一句：**人類智能價值穿越週期的不變量，是認知相變能力。**
