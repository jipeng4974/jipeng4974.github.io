1 - First Impressions of Omarchy

Post-install changes and hands-on experience with Omarchy

Installation notes

  • Disable Secure Boot: some BIOSes require setting an administrator password before Secure Boot can be turned off.
  • Disable Fast Boot: skipping device initialization during boot can cause boot or hardware-detection problems.
  • Boot in UEFI mode: make sure the installation media boots in UEFI mode.

Post-install changes

  • Input method: installed fcitx5 + Rime and switched to the simplified-Chinese scheme luna_pinyin_simp; copied in the missing OpenCC traditional-to-simplified dictionaries; removed the traditional/simplified toggle so output is always simplified.
  • Editor and AI assistant: installed VS Code and the Kimi CLI (/home/pog/.kimi-code/bin/kimi).
  • Wrapped Kimi as a graphical app: created ~/.local/share/applications/kimi.desktop plus an icon, fixed the systemd graphical-session PATH, used an absolute path in the .desktop Exec, and refreshed the desktop database, icon cache, and Omarchy menu.
  • Touchpad: enabled natural (macOS-style) scrolling via natural_scroll = true in ~/.config/hypr/input.lua.
  • Passwordless sudo for pacman: added pog ALL=(ALL) NOPASSWD: /usr/bin/pacman to /etc/sudoers.d/omarchy-pkg, so Kimi can run omarchy pkg add to install packages without an interactive root prompt.
  • Small-screen display tuning: disabled window opacity globally, removed inner and outer window gaps, and kept a 1px border to identify the focused window.
  • Terminal fonts: tried several Nerd Fonts, including Caskaydia, Iosevka Term, Monaspace, Victor Mono, Fantasque, Fira Code, Monofur, and Comic Shanns, then settled on ComicShannsMono Nerd Font. Also created a font skill to make it easy to find, install, and switch fonts later.
  • Codex execution policy: set approval_policy = "never" and sandbox_mode = "danger-full-access" in ~/.codex/config.toml, so new sessions run without approval prompts and with full local access by default.
  • MacBook touchpad gestures: enabled three-finger drag. Three-finger left/right swipes now switch immediately to the next/previous workspace, matching SUPER + TAB behavior and avoiding the less-smooth built-in swipe animation.

Hands-on experience

My Acer Swift 3 had been collecting dust for two years and was nearly unusable: on Windows the fan was constantly roaring. With Omarchy installed, it runs quietly and feels normal again.

The UI/UX is extremely clean and beautiful — minimalism is beautiful in itself.

Everything is text- and code-based, which makes it very agent-friendly. Most configuration tweaks and customizations can be handled with Kimi’s help.

On a 2019/20 MacBook, Omarchy feels even more complete: macOS-style natural scrolling and three-finger drag make one-handed touchpad use comfortable, and three-finger horizontal workspace switching is arguably faster than keyboard shortcuts. The Retina display also makes the Linux desktop and terminal text look crisp, and the Touch Bar above the keyboard works normally.

2 - E Ink Monitor

E Ink displays are primarily aimed at people with dry eye, but they also suit people with neural hypersensitivity as a way to avoid visually induced migraines.

Since middle school, exposure to high-frequency flicker, patterns at certain spatial frequencies, or strong light has occasionally triggered severe migraines—deep orbital and radiating headaches accompanied by autonomic symptoms such as nausea and general fatigue.

Over the years, ophthalmologists and neurologists could not offer an effective diagnosis or useful advice. I even found a rare disease that matched my symptoms closely, but my doctors did not accept it and simply called the problem visual fatigue. Other people’s visual fatigue is surely not this painful.

After many rounds of ophthalmic examinations ruled out common eye diseases and organic lesions, I concluded that the root of my visually induced migraine was neural specificity: a sensory-gating defect in the primary visual cortex combined with a hyperreactive trigeminovascular system.

  • The brain cannot effectively “low-pass filter” or suppress high-frequency temporal dynamic input, so visual signals produce disorderly, synchronized, paroxysmal discharges in the cortex.
  • The thalamocortical circuit lacks habituation to high-frequency rhythmic light. In most people, visual-cortex responses gradually attenuate under repetitive flicker; in mine, the response remains “non-habituated,” sustaining high-intensity activity until neuronal energy is depleted and the nervous system becomes overloaded.
  • These overloaded high-frequency signals descend through cortico-subcortical pathways—for example, from the occipital cortex to the thalamus and brainstem nuclei—abnormally activating the trigeminal ganglion and the caudal spinal trigeminal nucleus. This can trigger sterile inflammation and dysregulated vasoconstriction/vasodilation in the dura mater and periorbital vessels, releasing pain mediators such as CGRP (calcitonin gene-related peptide) and producing deep eye pain and radiating headache.

So I built a flicker-free, warm-light E Ink display system with a BOOX 13.3-inch e-ink monitor, a BenQ ScreenBar light, and a tablet stand to hold the light. It immediately relieved the physical pain.

Beyond that, keeping polarized glasses in the car is also crucial: when I encounter a half-broken traffic light flickering wildly, I can pull down the sun visor as well.

4 - My PC Build

The prebuilt PC I bought after returning home finally failed, so I built a PC myself for the first time.

Starting in 2024, back-connect motherboards became more common, offering a great deal of convenience for DIY builders. The B760M-BTF can be regarded as the back-connect version of the B760M-Plus. With this motherboard design, the CPU power cable and front-panel header connections no longer need to be routed through the crowded interior, which simplifies the build considerably.

Given my actual gaming and AIGC needs, the high-end configuration would not add much value, so I ultimately chose Configuration 1:

  • Enough performance to run a local txt2img and img2img pipeline.
  • A good balance of performance and visual quality across the games I wanted to play.
  • Capable enough for some QLoRA training on WSL2.
