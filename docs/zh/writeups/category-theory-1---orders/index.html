CAT01: Orders

CAT 系列第 1 篇，以序理论（order theory）为完整的范畴论做热身。内容涵盖 preorder、meet/join、monotone map 与 Galois connection。

预序（Preorders）

从 sets 和 subsets 出发，我们可以把 AAA 与 BBB 之间的 relation 定义为一个 subset R∈A×BR \in A\times BR∈A×B。

每个 function 都是一个 relation，满足 2 个性质：

  1. ∀a∈A\forall a \in A∀a∈A，存在 b∈Bb \in Bb∈B，使得 (a,b)∈R(a,b)\in \mathbb{R}(a,b)∈R
  2. ∀a,b1,b2\forall a, b_1, b_2∀a,b1​,b2​，若 (a,b1)∈R(a,b_1) \in R(a,b1​)∈R 且 (a,b2)∈R(a, b_2) \in \mathbb{R}(a,b2​)∈R，则 b1=b2b_1 = b_2b1​=b2​。

序（order）、等价（equivalence）、容忍（tolerance）都是 relation。

function f:A↣Bf: A\rightarrowtail Bf:A↣B 称为 injection（单射），如果 ∀a1,a2,b\forall a_1, a_2, b∀a1​,a2​,b，当 (a1,b),(a2,b)∈R(a_1, b), (a_2, b) \in R(a1​,b),(a2​,b)∈R 时，有 a1=a2a_1 = a_2a1​=a2​。

function f:A↠Bf: A\twoheadrightarrow Bf:A↠B 称为 surjection（满射），如果 ∀b∈B\forall b \in B∀b∈B，存在一个 a∈Aa \in Aa∈A，使得 f(a)=bf(a) = bf(a)=b。

function f:A↣≅Bf: A \overset{\cong} \rightarrowtail Bf:A↣≅​B 称为 bijection（双射），如果它既是满射又是单射。

集合 XXX 上的 identity function 记作 idXid_XidX​，即双射函数 idX(x)=xid_X(x) = xidX​(x)=x。

AAA 上的一个 partition（划分）无非就是到另一个集合 PPP 的满射：A↠PA \twoheadrightarrow PA↠P。

我们可以给 partitions 排序：A↠P1A \twoheadrightarrow P_1A↠P1​，A↠P2A \twoheadrightarrow P_2A↠P2​。如果存在一个 function P1→P2P_1 \rightarrow P_2P1​→P2​ 使下图交换：A↠P1→P2A \twoheadrightarrow P_1 \rightarrow P_2A↠P1​→P2​，则称 P1⩽P2P_1 \leqslant P_2P1​⩽P2​。

因此 A↠AA \twoheadrightarrow AA↠A 是最小的 partition，而 A↠1‾A \twoheadrightarrow \underline{1}A↠1​ 是最大的 partition。

preorder（预序）是

  1. 一个集合 SSS，以及
  2. 一个关系 ≤ ⊆S×S≤ \: \subseteq S \times S≤⊆S×S1

并满足 2 个性质：

  1. S≤SS ≤ SS≤S。2
  2. ∀S1\forall S_1∀S1​、S2S_2S2​、S3S_3S3​，若 S1≤S2S_1 ≤ S_2S1​≤S2​ 且 S2≤S3S_2 ≤ S_3S2​≤S3​，则 S1≤S3S_1 ≤ S_3S1​≤S3​。3

preorder 就是任意两个对象之间至多只有一个 morphism 的 category。稍微复杂一点的说法是：preorder 是一种 Bool-enriched category。

Meet 与 Join

序（order）催生了 meets 和 joins。

将 AAA 与 BBB 做 join，记作 A∨BA\vee BA∨B，得到的是同时大于 AAA 和 BBB 的最小 partition。即 A≤(A∨B)A ≤ (A\vee B)A≤(A∨B) 且 A≤(A∨B)A ≤ (A\vee B)A≤(A∨B)。并且对任意 C，若 A≤CA ≤ CA≤C 且 B≤CB ≤ CB≤C，则 (A∨B)≤C(A\vee B) ≤ C(A∨B)≤C。

形式化地说。设 (P,≤)(P, ≤)(P,≤) 是一个 preorder，A⊆PA \subseteq PA⊆P 是一个 subset。若元素 p∈Pp \in Pp∈P 满足以下条件，则称 ppp 为 AAA 的一个 meet：

  1. ∀a∈A\forall a\in A∀a∈A，都有 p≤ap≤ ap≤a4，并且
  2. 对所有满足"对任意 a∈Aa\in Aa∈A 都有 q≤aq≤ aq≤a“的 qqq，都有 q≤pq≤ pq≤p5。

记作 P=∧A=∧a∈Aa=a1∧a2∧...∧anP = \wedge A = \underset{a\in A}{\wedge} a = a_1 \wedge a_2 \wedge ... \wedge a_nP=∧A=a∈A∧​a=a1​∧a2​∧...∧an​

类似地，若满足以下条件，则称 ppp 为 AAA 的一个 join：

  1. ∀a∈A\forall a\in A∀a∈A，都有 a≤pa≤ pa≤p6，并且
  2. 对所有满足"对任意 a∈Aa\in Aa∈A 都有 a≤qa≤ qa≤q“的 qqq，都有 p≤qp≤ qp≤q7。

此时记作 P=∨A=∨a∈Aa=a1∨a2∨...∨anP = \vee A = \underset{a\in A}{\vee} a = a_1 \vee a_2 \vee ... \vee a_nP=∨A=a∈A∨​a=a1​∨a2​∨...∨an​

接下来讨论一些例子。

例 1：布尔值 B\mathbb{B}B={T,F}$ 的真值表。

例如，{T,F}(F≤T)\{T,F\}(F \leq T){T,F}(F≤T) 的两两 meets 表恰好就是初等逻辑中 AND 的真值表。类似的二元 join 计算会生成 OR 的真值表。

例 2：幂集 (P(x),≤)(P(x), ≤)(P(x),≤)。

取一个具体的集合，令 X={□,×,♡}X = \{\square, \times, \heartsuit\}X={□,×,♡}，然后考虑它的幂集：

在这种情况下，显然 ∧\wedge∧ = 交集（intersection），∨\vee∨ = 并集（union）。

例 3：(N,∣),a≤b(\mathbb{N}, |), a ≤ b(N,∣),a≤b 当且仅当 a∣ba|ba∣b

1 整除所有数，所以我们从 1 开始。这里 ∧\wedge∧ = gcd，∨\vee∨ = lcm。

例 4：meet/join 可能不止一个。

这张 Hasse 图给出了一个 preorder，其中 ccc 和 ddd 都是 AAA 的 meets。我们有 c≤dc≤ dc≤d 且 d≤cd≤ cd≤c，所以 c≅dc \cong dc≅d，即 ccc 与 ddd 是 isomorphic（同构）的，这一点后文会讲到；不过一般来说，我们把它们当作相等也不会遇到什么麻烦。

例 5：meet 或 join 可能不存在。

显然，事物并不总是有下界或上界。也可能存在多个下界/上界，但这些下界/上界之间不可比较。

纵观这些例子，许多熟悉的事物——无论是 gcd/lcm、max/min、limits/colimits，还是 intersection/union——都可以用这个相当简单的泛性质（universal property）来刻画。

事物可以由泛性质来刻画，这一想法意味着我们现在离范畴论更近了。

单调映射（Monotone Maps）

Preorders 自身之间也可以相互关联。monotone map 就是 preorders 之间保持结构的映射。

preorders (A,≤A)(A, ≤_A)(A,≤A​) 与 (B,≤B)(B, ≤_B)(B,≤B​) 之间的 monotone map 是一个 function f:A→Bf : A \rightarrow Bf:A→B，使得对所有元素 x,y∈Ax, y ∈ Ax,y∈A，若 x≤Ayx ≤_A yx≤A​y，则 f(x)≤Bf(y)f (x) ≤_B f(y)f(x)≤B​f(y)。

设 B\mathbb{B}B 为布尔值的 preorder，N\mathbb{N}N 为自然数的 preorder。把 false 映到 17、把 true 映到 24 的映射 B→N\mathbb{B} \rightarrow \mathbb{N}B→N 是一个 monotone map，因为它保持了序。

若 ∀p,p′∈P,f(p∨p′)=f(p)∨f(p′)\forall p,p' \in P, f(p\vee p') = f(p) \vee f(p')∀p,p′∈P,f(p∨p′)=f(p)∨f(p′)，则称 monotone map f:P→Qf: P \rightarrow Qf:P→Q 保持 joins。

对任意 preorder (P,≤P)(P, ≤_P)(P,≤P​)，恒等函数都是单调的。 若 (Q,≤Q)(Q, ≤_Q)(Q,≤Q​) 和 (R,≤R)(R, ≤_R)(R,≤R​) 是 preorders，且 f:P→Qf : P → Qf:P→Q 与 g:Q→Rg : Q → Rg:Q→R 都是单调的，则 (f;g):P→R(f ; g): P → R(f;g):P→R 也是单调的。

设 (P,≤P)(P, ≤_P)(P,≤P​) 与 (Q,≤Q)(Q, ≤_Q)(Q,≤Q​) 为 preorders。若存在一个 monotone function g:Q→Pg : Q → Pg:Q→P 使得 f;g=idPf;g = id_Pf;g=idP​ 且 g;f=idQg;f = id_Qg;f=idQ​，则称 monotone function f:P→Qf : P → Qf:P→Q 为一个 isomorphism（同构）。这意味着对任意 p∈Pp ∈ Pp∈P 和 q∈Qq ∈ Qq∈Q，都有 p=g(f(p))p=g(f(p))p=g(f(p)) 且 q=f(g(q))q =f(g(q))q=f(g(q))。

我们称 ggg 为 fff 的逆，反之亦然：fff 是 ggg 的逆。

若存在一个 isomorphism P→QP → QP→Q，则称 PPP 与 QQQ 是同构的（isomorphic）。

preorders 之间的同构，基本上只是对元素的重新标记（relabeling）。

Galois 连接（Galois Connections）

preorders PPP 与 QQQ 之间的 Galois connections 是一对 monotone maps f:P→Qf : P → Qf:P→Q 和 g:Q→Pg : Q → Pg:Q→P，满足 f(p)≤qiffp≤g(q).f(p) ≤ q iff p ≤ g(q).f(p)≤qiffp≤g(q).

我们称 fff 为左 adjoint（左伴随），g 为该 Galois connection 的右 adjoint（右伴随）。

Galois connections 的理论是一个更一般的理论——adjunctions（伴随）理论——的特例。

例 1：P=Q=3‾P = Q = \underline{3}P=Q=3​

此时 PPP 和 QQQ 都是全序（total order），只要箭头不交叉，fff 就是 ggg 的左伴随。

例 2：Z→f3×□R\mathbb{Z} \xrightarrow[f]{3\times\square} \mathbb{R}Z3×□f​R，R→g⌊□/3⌋Z\mathbb{R} \xrightarrow[g]{\lfloor\square/3\rfloor} \mathbb{Z}R⌊□/3⌋g​Z

归根结底，我们可以断言：monotone map fff 是左/右 adjoint，当且仅当它保持 joins/meets。
