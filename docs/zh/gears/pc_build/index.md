2024年开始出现一些背插主板，对DIY来说提供里极大的便利。B760M-BTF可以视作B760M-Plus的背插版本。背插主板的设计可跳过CPU供电插线和前置IO跳线的繁琐过程，使装机过程简化。

考虑实际游戏和AIGC需求，高配意义不大，最终选择配置1：
- 足以搭建本地的txt2img，img2img pipeline。
- 在所有目标游戏中获得理想的性能、效果平衡。
- 在wsl2上做一些QLoRA训练。
