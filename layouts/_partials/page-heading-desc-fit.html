{{- /* Project helper: decide how a page's description is presented in the heading. Applies to the writeups/games/photos/about/gears sections. The theme's .lead paragraph is never used for these pages — every description renders as .td-page-heading__desc; this helper only picks the layout mode: "inline" — the description sits to the right of the h1 in a narrow (22em) box. Allowed to occupy up to two lines in that box. "block" — longer descriptions sit under the h1 across the full content width. Width model: the h1 (1.75rem bold sans) costs ≈15px per Latin char and ≈30px per CJK char; the description (1rem serif) ≈9px / ≈18px. The inline box is 22em ≈ 352px wide, i.e. ≈39 Latin or ≈19 CJK chars per line, so "two lines" is 78 width units (Latin char = 1, CJK/wide char = 2 — rune count + non-ASCII count). On the row, the description never costs more than its box width (352px); the row fits under ~620px of content width plus a 20px gap. Input: a page. Returns: string; "" only for pages outside the listed sections or without a description (those keep the theme's heading-plus-lead layout). */ -}} {{- $mode := "" -}} {{- if and (in (slice "writeups" "games" "photos" "about" "gears") .Section) .Description -}} {{- $tPx := mul (add (strings.CountRunes .Title) (len (findRE `[^\x00-\x7F]` .Title))) 15 -}} {{- $dUnits := add (strings.CountRunes .Description) (len (findRE `[^\x00-\x7F]` .Description)) -}} {{- $dRaw := mul $dUnits 9 -}} {{- $dPx := cond (gt $dRaw 352) 352 $dRaw -}} {{- if and (le $dUnits 78) (le (add $tPx $dPx 20) 620) -}} {{- $mode = "inline" -}} {{- else -}} {{- $mode = "block" -}} {{- end -}} {{- end -}} {{- return $mode -}}
